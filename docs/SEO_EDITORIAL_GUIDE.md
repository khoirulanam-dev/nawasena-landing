# SEO Editorial Guide

## Article Basics

- Use one clear H1 as the article title.
- Keep slug lowercase with hyphens only.
- Keep excerpt buyer-focused and under roughly 240 characters.
- Keep meta description separate from excerpt.
- Use H2/H3 headings to structure the article.
- Avoid placeholders such as TODO, TBD, Lorem ipsum, `[IMAGE]`, and `[LINK]`.

## Body Formatting

Use the article editor syntax:

```text
Paragraph text.

## H2 heading

### H3 heading

- Bullet item
- Bullet item

1. Ordered item
2. Ordered item

> Callout or important note.
```

## Publishing

- Use Draft while writing.
- Use Published only after title, slug, excerpt, body, SEO title, meta description, image, alt text, author, schema type, and fact-check status are complete.
- Use Approved or Verified fact-check status for technical, export, quality, or market claims.

## Media

- Upload owned images whenever possible.
- Write descriptive alt text, not keyword stuffing.
- Add credit/source when an image is not owned by Nawasena.
- Do not upload SVG or GIF for articles.

## Conversion

- Select a related product when relevant.
- Select a CTA that matches the article intent.
- Prefer Java Ijen sample requests for Java Ijen sourcing content.
